# Bitnami Secure Image for Cass Cassandra

## What is Cass Cassandra?

> Apache Cassandra distributed NoSQL database bundled with the K8ssandra Management API agent, enabling HTTP-based node lifecycle management, metrics collection, and operator-driven cluster operations.

[Overview of Cass Cassandra](https://cassandra.apache.org)

This container image is only available under the [Bitnami Secure Images initiative](https://news.broadcom.com/app-dev/broadcom-introduces-bitnami-secure-images-for-production-ready-containerized-applications).
