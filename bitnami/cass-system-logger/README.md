# Bitnami Secure Image for Cass System Logger

## What is Cass System Logger?

> High-performance log collection and routing agent that aggregates, transforms, and ships Cassandra node logs to configurable destinations, based on the Vector observability pipeline.

[Overview of Cass System Logger](https://vector.dev)
