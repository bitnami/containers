# Bitnami Secure Image for Cass Operator

## What is Cass Operator?

> Kubernetes operator that manages the lifecycle of Apache Cassandra clusters in Kubernetes, providing automated deployment, scaling, and rolling upgrades through CassandraDatacenter CRDs.

[Overview of Cass Operator](https://k8ssandra.io)
