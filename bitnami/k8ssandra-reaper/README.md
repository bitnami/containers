# Bitnami Secure Image for K8ssandra Reaper

## What is K8ssandra Reaper?

> Automated repair service for Apache Cassandra that schedules and executes anti-entropy repairs to maintain data consistency across cluster nodes, reducing manual repair overhead.

[Overview of K8ssandra Reaper](https://cassandra-reaper.io)
