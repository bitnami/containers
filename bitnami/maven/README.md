# Bitnami Secure Image for Apache Maven

## What is Apache Maven?

> Apache Maven is a build and project management tool. It uses a POM (pom.xml) to handle builds, dependencies, docs, and publishing, and can be extended with plugins for reporting and other build tasks

[Overview of Apache Maven](https://maven.apache.org)

This container image is only available under the [Bitnami Secure Images initiative](https://news.broadcom.com/app-dev/broadcom-introduces-bitnami-secure-images-for-production-ready-containerized-applications).
