# Bitnami Secure Image for Cass Config Builder

## What is Cass Config Builder?

> Configuration builder for Apache Cassandra that generates cassandra.yaml and related configuration files from declarative templates, supporting multiple Cassandra versions and deployment models.

[Overview of Cass Config Builder](https://github.com/datastax/cass-config-builder)

This container image is only available under the [Bitnami Secure Images initiative](https://news.broadcom.com/app-dev/broadcom-introduces-bitnami-secure-images-for-production-ready-containerized-applications).
