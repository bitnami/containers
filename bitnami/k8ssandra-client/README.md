# Bitnami Secure Image for K8ssandra Client

## What is K8ssandra Client?

> CLI plugin and init container for K8ssandra that performs CRD upgrades, cluster connectivity validation, and operator bootstrap tasks in Kubernetes environments.

[Overview of K8ssandra Client](https://k8ssandra.io)

This container image is only available under the [Bitnami Secure Images initiative](https://news.broadcom.com/app-dev/broadcom-introduces-bitnami-secure-images-for-production-ready-containerized-applications).
