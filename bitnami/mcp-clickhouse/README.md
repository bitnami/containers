# Bitnami Secure Image for ClickHouse MCP Server

## What is ClickHouse MCP Server?

> ClickHouse MCP Server lets AI assistants run safe, read-only SQL queries and browse databases or tables in ClickHouse and chDB.

[Overview of ClickHouse MCP Server](https://github.com/ClickHouse/mcp-clickhouse)

This container image is only available under the [Bitnami Secure Images initiative](https://news.broadcom.com/app-dev/broadcom-introduces-bitnami-secure-images-for-production-ready-containerized-applications).
